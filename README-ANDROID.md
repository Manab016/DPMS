# DPMS - Android Cordova App

## আপনার HTML অ্যাপ্লিকেশন Android এ রূপান্তর

এই branch এ আপনার সম্পূর্ণ DPMS (Durga Puja Management System) অ্যাপ্লিকেশন Cordova এর সাথে সেট আপ করা হয়েছে।

### সব ফাইল সংরক্ষিত আছে:
✅ `dashboard.html` - ড্যাশবোর্ড
✅ `members.html` - সদস্য ব্যবস্থাপনা
✅ `chada.html` - চাঁদা সংগ্রহ
✅ `expense.html` - খরচ ট্র্যাকিং
✅ `settings.html` - সেটিংস
✅ `Logo.png` - আপনার লোগো

### কীভাবে Android APK তৈরি করবেন?

**ধাপ ১:** Node.js এবং Android Studio ইনস্টল করুন
**ধাপ ২:** Cordova CLI ইনস্টল করুন
**ধাপ ৩:** এই রিপো ক্লোন করুন
**ধাপ ৪:** `npm install` চালান
**ধাপ ৫:** `cordova build android` চালান
